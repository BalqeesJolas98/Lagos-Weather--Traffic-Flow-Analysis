# Local data

Place the two study workbooks in this directory before running the analysis. Raw Excel data are intentionally excluded from version control by .gitignore.

Accepted filenames:
- DRY_SEASON_DATASET.xlsx or DRY_SEASON_DATASET DEC- JAN.xlsx
- WET_SEASON_DATASET.xlsx or WET_SEASON_DATASET APR- MAY.xlsx
